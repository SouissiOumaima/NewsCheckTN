# Silver Lot A1 — Limites semantiques NLI

Date : 2026-11-19
Statut : documentation provisoire

## 1. Provenance et attribution
Les articles de fact-checking peuvent rapporter
des declarations sans prouver independamment
les faits mentionnes.

## 2. Precision temporelle
P263 : la date et le declarant ne sont pas
etablis par l'extrait isole. Le contexte
complet doit etre conserve pour justification.

## 3. Affirmations attribuees
P276 et P289 : le label supports concerne
la fidelite aux declarations rapportees.

## 4. Cas bilingues FR-AR
P299 : supports
P300 : refutes
P301 : supports
P302 : refutes
P303 : neutral

Les traductions et attributions doivent
etre interpretees avec leur contexte source.

## 5. Limites scientifiques
- Une attribution ne constitue pas une preuve
  independante des faits.
- Les extraits tronques peuvent omettre
  des informations determinantes.
- Les conclusions NLI portent sur la relation
  claim-evidence.
- Les cas ambigus necessitent une revue humaine.

## 6. Reproductibilite
Les 34 paires ciblees disposent de cles
d'articles et de splits verifies.
Aucun chevauchement par article detecte
sur les 263 paires reparties.
