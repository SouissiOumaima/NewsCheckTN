Tableau de bord d'évaluation

Tous les fichiers de résultats écrits par les scripts d'évaluation des lots dans evaluation/results/ (format commun de evaluation/README.md). Chaque ligne renvoie à une entrée de experiments.md par son identifiant.

Les synthèses légères de revue sont versionnées ; le tableau affiche aussi les résultats générés localement. Pour les mettre à jour, lance les évaluations de chaque lot et python -m evaluation.integration_audit.
